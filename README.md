# Weby Major

Verze připravená pro GitHub a automatické nasazení na Vercel.

## Nasazení

1. Nahrajte obsah této složky do kořene GitHub repozitáře.
2. Ve Vercelu importujte daný repozitář.
3. Framework Preset ponechte na `Next.js`.
4. Root Directory ponechte prázdný a Output Directory nenastavujte ručně.
5. Spusťte Deploy.

Kontaktní formulář odesílá data přes Formspree.
